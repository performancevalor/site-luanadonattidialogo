# Site Luana Donatti

Site profissional e mobile-first de Luana Donatti, gerente de vendas da Diálogo e líder da Equipe Luana JD.

## Estrutura

- página inicial de autoridade;
- trajetória, resultados, equipe, imóveis, recrutamento e contato;
- dez páginas individuais de empreendimentos;
- formulário profissional integrado ao Google Sheets por Vercel Function e Google Apps Script;
- SEO técnico, dados estruturados e sitemap.

## Desenvolvimento

```bash
npm run validate
```

## Integração do formulário

1. Publique `integracao/google-apps-script.gs` como aplicativo da web executado pelo proprietário e acessível a qualquer pessoa.
2. Defina a variável `APPS_SCRIPT_URL` no projeto da Vercel com a URL `/exec` da implantação.
3. Faça um envio real e confirme a nova linha em `CANDIDATOS E PARCERIAS`.

As condições dos empreendimentos devem ser reconfirmadas antes da publicação de campanhas ou materiais comerciais.
